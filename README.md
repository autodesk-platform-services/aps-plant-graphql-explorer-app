# How to use it
## Set client configuration
This client supports two kind of login OAuth2 and OAuth2 with PCKE.
![image](https://git.autodesk.com/AEC-Design-Systems/Autodesk.Plant.GraphQL.Explorer/assets/2762/d801ae57-8939-4034-8812-bef5819bc299)
![image](https://git.autodesk.com/AEC-Design-Systems/Autodesk.Plant.GraphQL.Explorer/assets/2762/4056e363-fbc0-4c56-b000-0315312622a7)

At least set one of them, then the login button is enable.

## Login in the popup browser
Step by step login on browser with Autodesk account
![image](https://git.autodesk.com/AEC-Design-Systems/Autodesk.Plant.GraphQL.Explorer/assets/2762/bd69f58d-ee89-4681-840a-660b3d9f54ee)

## Export to CSV
After searching data, click "Export CSV" button can export all data searched to csv file.
